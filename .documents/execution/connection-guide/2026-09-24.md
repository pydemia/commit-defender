# 확장 내부 GCR 연결 가이드 — 2026-09-24

Commit Defender 2.12.7에 GCR 연결과 첫 리뷰 가이드를 포함하고 macOS ARM64에
로컬 설치했다. VS Code 표시 언어(`vscode.env.language`)가 `ko` 또는 `ko-*`이면
한국어를, 나머지는 영어를 선택한다. 두 문서 상단에는 상호 전환 링크를 둔다.
GCR 접속이나 계정 설정 없이 번들 문서를 읽을 수 있다.

진입 경로는 명령 팔레트의 `Commit Defender: GCR Connection Guide`, CD 사이드바
상단의 도움말 아이콘, `Central Review Connection → GCR connection guide`다.
VS Code 내장 Markdown 미리보기를 사용하며 미리보기 명령을 사용할 수 없으면
텍스트 편집기로 문서를 연다.

## 구현과 reference

`reference-led-frontend`와 agent-skills 원격 추적 브랜치의
`frontend-development` 지침을 적용했다. 기존 CD Quick Pick 메뉴와 VS Code에
설치된 Markdown 확장의 `markdown.showPreview` 명령을 확인하고 재사용했다.
새 webview·스타일·외부 문서 서버는 추가하지 않았다.

가이드는 reader key와 연결 JSON 발급, 로컬 계정·모델·reasoning 선택, HTTPS,
동기화·이력 조회, 첫 리뷰와 출처 확인, 인증·서버·모델 오류 구분을 설명한다.
실제 서버와 확장 코드의 명령·동작을 대조했다. 특정 사내 주소·계정·키는
문서에 포함하지 않았다.

## 검증 결과

- TypeScript typecheck와 build 통과.
- 기존 `test:central-view` 6건 통과. macOS 기본 LibreSSL에서는 TLS fixture
  생성이 실패해 Homebrew OpenSSL 3을 해당 명령의 PATH에 지정했다. 제품의
  인증서 검증은 변경하지 않았다. 초기 시험이 만든 `-` 파일은 삭제했다.
- 실제 VS Code 1.137.0 Extension Host에 최종 VSIX를 풀어 활성화하고 가이드
  명령을 실행했다. 영어 환경은 `central-setup.md`, 한국어 환경은
  `central-setup.ko.md`의 Markdown 미리보기 탭이 열리는 것을 확인했다.
- 한국어 검증은 시험 전용 user-data와 extensions 디렉터리를 사용했다.
  language pack 설치만으로는 첫 시작의 표시 언어가 바뀌지 않아 언어 캐시를
  초기화한 뒤 같은 시험 profile에서 다시 시작했다. 이때 실제
  `vscode.env.language === 'ko'`를 확인했다. Microsoft 언어팩 다운로드는
  인증서 체인 오류로 실패했으며 검증을 완화하지 않고 기존 설치된 언어팩을
  시험용으로 재사용했다. 사용자의 언어 설정과 언어팩은 변경하지 않았다.
- 두 문서의 상호 링크와 나머지 상대 문서 링크가 VSIX 안에 존재함을 확인했다.
- 사용자 settings.json의 설치 전후 해시와 각 시험 Host의 CD 설정이 같다.
  실제 리뷰·모델 호출은 0회다.

기존 central-view mock 테스트는 새 가이드 경로를 실행하지 않는다. 가이드 열기는
위 실제 Host에서 별도로 확인했다. 사이드바·연결 메뉴의 진입점은 manifest와
소스로 확인했으며 해당 메뉴를 클릭하는 UI 자동화나 screenshot은 이번 근거에
포함하지 않는다. Markdown 미리보기 비활성화 시 텍스트 fallback도 실행 검증하지
않았다. 이번 macOS 검사는 Windows·Linux 네이티브 실행 검증을 대신하지 않는다.

## 적용 상태와 사용 방법

로컬 설치는 완료했지만 이미 열린 사용자 Extension Host를 강제로 다시 로드하지
않았다. 명령이 보이지 않으면 진행 중인 작업을 마친 뒤 사용자가
`Developer: Reload Window`를 실행하거나 VS Code를 다시 시작한다. 이후 명령
팔레트에서 `Commit Defender: GCR Connection Guide`를 실행한다.

Marketplace 게시는 보류했다. GCR runtime 변경과 재배포는 없다. 시험 workspace,
전용 user-data·언어팩·extensions 디렉터리는 시험 종료 시 제거하며 사용자 계정과
provider·모델·자동 실행 설정은 유지한다.
