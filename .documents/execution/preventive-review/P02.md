# P02 실행 기록

상태: 진행 중. P02-C01의 공통 계약을 CD에서 소비하는 검증을 완료했다. Runtime backend 통합은 P02-C07에 남아 있다.

## C01 계약 소비

GCR source commit `5af394dacb195d95526efb497fff05706cafa53b`의 `@gcr/client-contract@0.1.0-alpha.2`를 상대 `file:` devDependency와 lockfile integrity로 고정했다. GCR checkout이나 sibling source를 import하지 않는다. 세 client tarball과 manifest를 `vscode-extension/vendor/gcr/0.1.0-alpha.2`에 보관하되 core/executors는 아직 identity만 제공하므로 설치·실행 backend에 연결하지 않았다. Vendor와 test fixture는 VSIX에서 제외한다.

`test/fixtures/client-contract/reports.json`은 GCR의 같은 파일과 byte 단위로 일치한다. SHA-256은 `95195bdec5d49201994ced3f40e8db11ae8e1f47e5dd3bf553154bb0f3224711`이며 전달 commit·version은 옆의 `provenance.json`에 있다. Fixture는 합성 자료다. Source·base 본문과 Git/hash identity를 고정했고 실제 모델·runner·GUI 호출을 수행한 것으로 표시하지 않는다.

## 변경과 검증

CD의 `IncompleteReason`과 `SourceExclusionReason` 타입에 공통 계약의 미완료·제외 사유를 추가했다. Missing context를 truncation으로 바꾸지 않고 원래 사유를 보존한다. 실행 backend와 기존 hook 판정 동작은 바꾸지 않았다.

`test:client-contract`는 설치된 package에서 생성한 projection을 실제 `AnalysisReport`에 대입해 typecheck하고 CD normalizer·outcome·source overlay·advisory adapter에 전달한다. 12개 report 상태, 기존 verified/high와 unassessed 분리, source 변경 후 overlay 무효화, exception과 전체 evidence의 JSON 보존, summary에서 finding을 만들지 않는 동작을 검사한다. 새 projection은 advisory이고 P3를 보존한다. 기존 `legacy-hook`의 P3 차단 여부를 별도 검사해 두 경로의 의미를 혼동하지 않는다.

2026-09-13 검증:

- `npm ci --offline --ignore-scripts --no-audit --no-fund` 후 전체 `npm test`: 90개 통과. Provider 7, source policy 10, Git snapshot 14, outcome 23, security 9, backend 10, contract 17이다.
- `npm run typecheck:test`, `npm run build`: 통과. Production bundle은 재생성 후 기존 commit과 차이가 없다.
- Node 18.20.8에서 설치 contract를 bundle한 `out-test/client-contract.test.cjs`: 17개 통과. 최종 fixture formatting/hash 동기화 뒤에도 다시 통과했다.
- `git diff --check`: 통과. Tarball과 fixture SHA-256은 test가 직접 대조한다.

새 backend·memory/Skill UI·credential migration은 구현 전 상태다. P01 실제 리뷰 화면은 Mac 잠금으로 미검증이며 이번 JSON/normalizer 검사를 GUI 통과로 계산하지 않는다. Marketplace version과 게시 artifact는 변경하지 않았다. GCR 서버 runtime 변경도 없어 이번 C01에서 PRISM-DEV를 rollout하지 않았다.
