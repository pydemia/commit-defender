# P12 — 코드 변경에서 발행한 기준 수신

## 2026-09-15 — Commit Defender 2.9.4

중앙 코드 변경의 출처 참조를 포함하는 지식 계약 v3을 지원한다. Client libraries alpha37과 CLI alpha33을 함께 묶었다. 기존 v2도 읽으며 이전 서버의 HTTP 426에 한해 같은 서버에 v2를 한 번 요청한다. 다른 인증·네트워크 실패에는 계약 협상을 하지 않는다.

중앙에서 승인·발행한 기준과 출처 ID/hash만 내려받고 로컬에 설정한 모델·계정으로 리뷰한다. 중앙 코드 diff·metadata 원문을 내려받거나 로컬 source/결과/피드백을 업로드하는 경로를 추가하지 않았다. 자체 HTTPS fixture의 v3 기준을 로컬 합성 실행기에 전달하고 이력을 복원하는 검사에서 모든 중앙 통신이 GET이며 제출은 0회였다.

확장 회귀 190건, source/test typecheck와 build를 통과했다. 실제 VSIX를 VS Code 1.90.2와 설치된 1.135.0에서 활성화해 25개 명령, 자동 실행 기본값, 중앙 executor와 제출 명령 부재를 확인했다. 설치된 38개 파일과 package metadata·등록 정보가 VSIX와 일치한다. 사용자 창 reload와 전역 CLI 교체는 하지 않았다.
