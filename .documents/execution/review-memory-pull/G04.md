# G04 — 이력 활용 검증과 CD 전달

G04를 완료했다. [GCR의 전체 실행 기록](https://github.com/pydemia/git-code-reviewer/blob/ef4c51ea86471f22cfc0a0bb405c243e9e38cc5c/.documents/execution/review-memory-pull/G04.md)에 A01–A08 근거·실제 결과·호출 한도·정리·한계를 기록했다.

최종 CD는 2.11.3, 제품 package commit은 `57220c4`다. 공통 artifact source는 GCR `efd53207819c2105f0034a13f1be193f4a972e4c`, client 3종 alpha.42, 내부 service alpha.37이며 vendor manifest/provenance에 정확한 hash를 고정했다. VSIX SHA-256은 `0e7123c5ba5fd62d5a17df3307c6a50df3ea170dbedb3435eab2e673a7825333`다.

기존 기본 Codex 계정의 Luna/high로 원문 PR #917의 검증 지침과 #915 이력을 사용했다. 초기 3회 중 fixed는 manifest 만료로 취소됐고 완료된 두 결과에는 활용 설명이 없었다. 이를 보완한 추가 3회는 결함 107,932ms/P2 1건, 수정 136,346ms/0건, 무관 65,632ms/0건으로 모두 완료됐다. 총 6회이며 각 240초 한도를 유지했다. 실제 결과와 context 제공 증거를 구분했고 경계값 테스트 파일은 읽기 문맥으로만 사용했다.

제품 수정은 과거 자료가 있을 때 기존 결과 요약에 출처·적용 판단을 설명하도록 한 공통 프롬프트와, 그 요약을 파일별 요약과 함께 보이게 한 CD 화면이다. 2.11.2와 최종 2.11.3의 모델 worker·공통 package는 동일하다. 최종 Host에서 실제 세 결과를 기존 Summary 명령으로 열고 출처·버전·요약 renderer를 확인했다. 이 표시 검사는 모델 호출 0회다.

설치 bytes는 VSIX와 일치하며 사용자 settings hash는 유지됐다. 이미 열린 사용자 Host의 적용 버전은 미확정이고 강제 재로드하지 않았다. GCR runtime/Helm 배포는 변경하지 않았으며 Marketplace 게시를 보류했다. 임시 키·로그인 세션·검증 프로필을 정리했다. 기본 계정·provider·모델·자동 실행 설정과 원래 WIP는 보존했다.

`Commit Defender: Central Review Connection → Browse PR review history`에서 원문·답글·버전·지침을 확인하고 `Commit Defender: Analyze Staged Files`로 수동 리뷰를 실행한다. 새 설치 적용은 사용자가 편한 시점에 창을 다시 열거나 재로드할 때 확인한다. 온라인 manifest의 5분 제한은 그대로이며 취소·실패·partial 결과를 성공으로 취급하지 않는다. 다른 provider는 기존 회귀 범위로만 확인했다.
