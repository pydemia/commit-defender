# W02 — Windows 중앙 pulling 실행 기록

상태: 진행 중. 실제 중앙 pulling과 Luna/high 세 사례가 남아 있다.

시작 SHA는 CD `aee8b2246bf82e98dbc88de5afd789fd2d1c92bd`,
GCR `662825083579172cc24d4cdc5ee7f6106865a3f1`이며 양쪽
`codex/windows-native-support`는 fetch 후 원격과 일치하고 clean이었다.
설치 기준은 Windows ARM64 VSIX 2.12.2/client alpha.47/helper 1.0.1이다.
기존 열린 사용자 Host의 적용 버전은 미확인이고 강제 reload하지 않는다.

기존 G04 fixture의 defect/fixed/unrelated를 재사용한다. 결함 사례는
model_validator가 미호출 자유 함수가 된 오류를 과거 지침과 연결해야 한다.
수정 사례는 validator 복원을 확인하고 같은 오류를 반복 지적하지 않아야
한다. 무관 사례는 service의 DB archived 상태 검사를 schema로 옮기라고
요구하지 않아야 한다. source/base/caller/동작 규칙/경계값 테스트를 고정한다.

실제 모델 초기 한도는 기존 기본 Codex 계정의 `gpt-5.6-luna / high`,
각 사례 1회, 총 3회, 회당 240초다. 현재 호출 수는 0회다. 실제 계정 응답과
합성 검사는 구분한다. 완료 판정에는 출처 ID/URL/revision/hash 대조,
모델의 적용/충족/제외 설명, 저장 결과 재조회가 필요하다.

Windows의 `pr-review.prism.ai` DNS 조회가 실패했고 기록된
`10.250.107.189:443` 연결도 timeout이었다. 기본 CD 경로에 중앙 연결은
없었다. 접속 경로와 reader 연결 준비 위치를 확인하는 동안 독립 회귀를
진행한다. TLS·권한·만료·격리 검사를 완화하지 않는다.
